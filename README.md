# Morpion en Java Swing

MALLEM Moncef - Paris Ynov Campus - 2026 / 2027.

## Lancer dans IntelliJ

1. Choisir **Fichier > Ouvrir**, puis le dossier **Morpion** contenant `src` et `Morpion.iml`.
2. Sélectionner un **JDK 17 ou plus récent** si demandé, puis ouvrir `src/Gestion.java`.
3. Cliquer sur le **triangle vert à côté de `main`**. La classe `Gestion` lance le jeu.

## Fonctions

- Noms des deux joueurs.
- Mode deux joueurs ou contre l'ordinateur.
- Grille de neuf cases.
- Historique des coups avec noms et coordonnées.
- Sauvegarder et recharger une partie.
- Rejouer et quitter.
- Chronomètre facultatif de dix secondes par coup, avec défaite si le temps est écoulé.
